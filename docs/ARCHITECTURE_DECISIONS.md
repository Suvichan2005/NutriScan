# Architecture decisions

21 October 2026 · local development

1. **Standalone typed monolith.** Next.js App Router, React and TypeScript keep UI, request validation and official SDK adapters together. No existing source, remote or branch existed; initialized local Git `main`. Nothing in Flowmate was changed or used as a credential/data source.
2. **Browser owns photos.** Tesseract 7 worker, WASM and English trained data are served locally. Canvas handles rotation, scaling, contrast/inversion and bounded crops. Original blobs live only in the current component session. OCR line observations include side, confidence and prepared-image coordinates. Gemini receives no photo merely because OCR ran.
3. **Evidence before prose.** Zod schemas define observations, package readings, sources and profile inputs. Parser preserves missing/zero, duplicate conflicts, multilingual aliases and explicit mass/volume bases. Pure deterministic nutrition uses compatible observations and exposes formulae. No disease-based carb allowance, universal safe portion or brand risk score.
4. **Two retrieval paths.** Exact additive lookup plus local lexical/concept retrieval support the no-key audit. A genuinely pretrained MiniLM q8 encoder provides measured local hybrid semantic retrieval over seven versioned short source summaries. Source text/URL fingerprint invalidates stale vectors. This is a tiny acceleration corpus, not a full knowledge boundary or a clinical benchmark.
5. **Explicit public integrations.** Public product, literature, WHO discovery and US recall requests use allowlisted hosts, bounded response sizes and timeouts, same-origin loopback gate and rate/concurrency limits. Product records retain bases and identity uncertainty. FSSAI JS shells fail as unusable evidence. No arbitrary URL-fetch tool is exposed.
6. **Gemini optional and fail closed.** Official `@google/genai`, server key and model plus enable flag. Separate synthesis and vision calls avoid unverified mixed tool APIs. Synthesis can request one existing browser image handle/crop; the user sees its reason before sending. Numeric model disagreements never silently replace OCR. Structured output, citation-membership and handle checks do not prove source entailment. Provider acceptance remains blocked.
7. **Storage is deliberate.** Opt-in IndexedDB saves extracted label text and corrections, not photos or free-text health context. Twenty recent records. JSON reports omit original photos and free-text profile. No accounts, backend persistence, Firebase, sync or E2EE claims.
8. **Evidence has levels.** Unit/evaluation fixtures, real HTTP source receipts, browser screenshots, genuine-photo OCR and real provider acceptance remain separate. Photos from Open Food Facts are attributed but ignored in Git. No public publication is authorized.

Pinned dependencies live in package-lock.json; package.json also records exact installed versions. Local models and OCR assets are reproducible setup outputs and ignored. Academic team contracts remain modular: perception/browser, knowledge/retrieval, orchestration/calculation, UI/integration/evaluation.
