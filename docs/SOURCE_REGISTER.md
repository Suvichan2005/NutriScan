# Integration source register

Reviewed 22 October 2026 IST. These entries describe API methods and source provenance; static documentation or a dated snapshot does not establish current law or medical advice.

| Source | Primary URL | Use and limits |
| --- | --- | --- |
| USDA FoodData Central downloads | https://fdc.nal.usda.gov/download-datasets/ | Local structured import of Foundation Foods (April 2026) and FNDDS 2021–2023 (released October 2024). Source files are pinned by SHA-256 and kept out of Git; transformed indexes retain food IDs, publication/release dates, nutrient methods, sample metadata, portions, source links and CC0 attribution. Foundation is generic U.S. food data; FNDDS is a U.S. dietary-survey record set and its idli/roti entries are not canonical Indian values. All composition values use the source per-100-g edible-portion basis. |
| USDA Foundation Foods documentation | https://fdc.nal.usda.gov/Foundation_Foods_Documentation/ | Sampling, analytical/derived nutrient methods, per-100-g edible-portion basis and source-level variation; values are not a branded package or individualized target. |
| USDA FNDDS 2021–2023 documentation | https://www.ars.usda.gov/ARSUserFiles/80400530/pdf/fndds/2021_2023_FNDDS_Doc.pdf | FNDDS foods and portions from What We Eat in America/NHANES; composition values are per 100 g edible portion. U.S. survey definitions and portion examples must remain explicit; never treat them as Indian population ground truth. |
| Open Food Facts official API guide | https://openfoodfacts.github.io/openfoodfacts-server/api/ | Exact v2 barcode lookup; explicitly says full-text search is not available in v2. Crowdsourced data, not manufacturer verification. |
| Open Food Facts Search-a-licious API | https://openfoodfacts.github.io/search-a-licious/users/ref-openapi/ | Fixed `/search` POST body, selected fields, bounded candidates. India tag plus local filtering; no local stock proof. |
| Europe PMC REST service | https://europepmc.org/RestfulWebService | JSON core search, publication metadata/abstract. Default search relevance does not establish evidence quality or applicability. |
| openFDA food-enforcement overview | https://open.fda.gov/apis/food/enforcement/ | Historical US enforcement records. FDA expressly warns against public-alert/lifecycle use; recorded status may not be updated. Does not establish Indian recalls or brand-wide safety. |
| openFDA endpoint usage | https://open.fda.gov/apis/food/enforcement/how-to-use-the-endpoint/ | Public fixed `/food/enforcement.json` endpoint; no key required for these bounded calls; selected search, limit and sort parameters. |
| openFDA searchable fields | https://open.fda.gov/apis/food/enforcement/searchable-fields/ | Product, firm, reason, classification, report/initiation dates, distribution and lot/code fields. Missing data stays missing. |
| Google GenAI Models SDK reference | https://googleapis.github.io/js-genai/release_docs/classes/models.Models.html | Official `models.generateContent` call; no provider invocation was performed. |

NutriScan stores a concise original summary and link, not the PDF or reproduced text. Downstream redistribution terms were not independently reviewed. This does not establish current law, product classification, applicable basis or claim compliance. |
